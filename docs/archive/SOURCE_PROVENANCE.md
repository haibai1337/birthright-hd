## Separation and distribution

M1A extends this record with [ANUIRE_SOURCE_MATRIX.md](ANUIRE_SOURCE_MATRIX.md) and [ANUIRE_RECONSTRUCTION.md](ANUIRE_RECONSTRUCTION.md). The PC guide's relevant domain/military/spell/character sections, historical source serialization/initialization modules, atlas samples and actual modding thread were examined. The historical source was consulted in memory at pinned revision `fc47055002c4b776bfb1e8737b5aaf7f6d43edce`; no implementation code or source checkout was incorporated. Private extraction includes record-level offsets/confidence and hashed inputs. Aggregate coverage is tracked; original campaign records, derived contours and cached prose stay private. The local-file preview imports data at runtime and does not package it into releases.

`reference/original/*`, `reference/extracted/`, and research caches are ignored. The original-input README is the sole tracked exception in the originals directory. Vite's build root is `apps/game/` and only its `public/` plus imported application modules become web artifacts. Tauri bundles the compiled frontend; no reference-directory resource glob is configured.

M1C implements the private asset-pack loader and read-only extraction pipeline. The user's disc supplies 9,501 decoded records, retained under ignored `reference/private-assets/`. The runtime loads presentation-only paths and provenance; campaign rules do not depend on original artwork/audio. The separate clean web build excludes the pack. `npm run build:private` creates `apps/game/dist-private/`, marked private; the opt-in desktop hook creates a private native build. These private outputs must not be redistributed.

M1C's pinned historical-source inspection supplied factual resource filenames, indices and audio cue identifiers only; no source implementation was copied. Original Windows screenshots were used for visual comparison. The requested Spriters Resource page could not be accessed, so its collection's asset count has not been independently reconciled. See [ORIGINAL_ASSET_INVENTORY.md](ORIGINAL_ASSET_INVENTORY.md), [ORIGINAL_UI_RECONSTRUCTION.md](ORIGINAL_UI_RECONSTRUCTION.md) and [ORIGINAL_AUDIO_RESEARCH.md](ORIGINAL_AUDIO_RESEARCH.md) for exact sources, extraction limits and missing recordings.

Before a public Birthright-branded release, obtain the necessary permissions for use of protected setting/brand/trademark material and any original artwork, text, maps, audio, or proprietary code that would be included. A user's ownership of a disc or an “abandonware” label is not treated as redistribution permission. Verify the relevant rights holders rather than infer them from a 1997 publisher attribution.
