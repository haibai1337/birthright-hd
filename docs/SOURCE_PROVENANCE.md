## Separation and distribution

`reference/original/*`, `reference/extracted/`, and research caches are ignored. The original-input README is the sole tracked exception in the originals directory. Vite's build root is `apps/game/` and only its `public/` plus imported application modules become web artifacts. Tauri bundles the compiled frontend; no reference-directory resource glob is configured.

The asset-pack interface contains presentation-only paths and provenance. A separately supplied, appropriately licensed asset pack can eventually replace placeholders without changing campaign rules. It is currently an extension contract, not a completed user asset-pack loader.

Before a public Birthright-branded release, obtain the necessary permissions for use of protected setting/brand/trademark material and any original artwork, text, maps, audio, or proprietary code that would be included. A user's ownership of a disc or an “abandonware” label is not treated as redistribution permission. Verify the relevant rights holders rather than infer them from a 1997 publisher attribution.

No overall license for third-party references is granted by this repository. This session does not relicense the setting or distribute original-game assets. Original-code prototype development proceeds independently of those permissions.
