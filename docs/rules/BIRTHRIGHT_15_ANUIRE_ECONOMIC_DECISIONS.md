# Birthright 1.5 — Remaining economic decisions

**2026-10-24. Proposals for approval, not implemented rules.** Read with the [complete accounts](BIRTHRIGHT_15_ANUIRE_ECONOMIC_VALIDATION.md), [character evidence](BIRTHRIGHT_15_ANUIRE_CHARACTER_CONVERSION.md) and [court/development study](BIRTHRIGHT_15_ANUIRE_COURT_AND_GROWTH.md).

**J01–J08 are closed.** None of the options replaces net collections, passive Law, real positive trade endpoints/no trade RP, Source virtual cash, skill-sensitive RP, expanded courts, staged Contest, explicit commitments, or Basic automatic / Advanced guided / Expert manual control. Recommendations below are deliberately separate from those confirmed decisions. Original records remain intact under every option.

Birth/invested succession must use the same scale, conserved reserves and a later explicit inheritance contract rather than generating heirs now. Chapter 5's 2S/5S conflict is not another recommended interpretation.

## Approval boundary

These choices settle the economic package's major parameters. They do not approve missing skill ranks, overwrite original court/bloodline records, normalize imported excesses, fabricate ships/palaces/contracts, or migrate existing saves. Exact Contest recovery/opposition, occupation strength/duration/targets, ceremony prerequisites and full attitude/default consequences still need a connected rules draft using the selected economic prices. Evidence gaps should remain marked instead of being silently decided by implementation.

After approval: prepare the reviewed character overlays, rerun the same complete ledgers with the approved parameters and cost intended actions/services explicitly. Only then can the RP-financed and developed economy receive a final viability judgment. No implementation follows merely from completing this research.
