# Gameplay systems

Anuire is the only application campaign. It contains 206 provinces, 51 domains and 116 original regent records, with 18 currently selectable regents. Active territorial and holding domains use the same deterministic command validation as the player. With a territorial player, 48 domains use AI and two unused/placeholder domains remain passive.

Each season grants three domain actions. Rule provinces, improve holdings, change taxes, build fortifications, recruit basic troops, march armies and conduct diplomacy through the council windows. End season runs valid AI orders, taxation, upkeep, regency and seeded events. Relief petitions must be resolved before further orders. Manual saves, autosaves and exported/imported JSON saves are supported.

| System               | Current implementation                                                                                                                                                                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Province development | Guaranteed +1 level for current level + 2 GB, current level + 1 RP and one action; ceiling 10 or a higher preserved starting level                                                                                                                             |
| Holdings             | Law, guild, temple and source ownership is independent of territorial ownership. Improve costs current holding level + 1 GB, 1 RP and one action. Ten original capacity excesses are preserved; improvements cannot enlarge an over-capacity pool              |
| Tax                  | Original light/moderate/severe ranges from PC help section 126, uniformly sampled with the campaign PRNG. Forecasts use the floor of the mean; loyalty zero prevents provincial tax                                                                            |
| Income/maintenance   | Simplified guild/temple income, province and fort maintenance, verified upkeep for three basic unit types. Full court, law, tribute and trade rules remain incomplete                                                                                          |
| Regency              | Collection is capped by bloodline strength. Warrior law, wizard sources, priest temples and rogue guilds contribute under simplified class mappings                                                                                                            |
| Loyalty              | Runtime 0–4 scale. Light taxation improves loyalty, severe reduces it. Original delayed penalties and law protection are incomplete                                                                                                                            |
| Recruitment          | Infantry: 2 GB, 1 upkeep, minimum province 1. Archers: 2/1/2. Cavalry: 4/2/3. One action per unit. Combat powers 6/5/10 are experimental                                                                                                                       |
| Imported units       | Native type IDs remain separate; 20/21/23 reuse archer/cavalry/infantry balance. Other types use power 5/upkeep 1. Native variants are not recruitable pending decoding. Characters are separate noncombat deployments                                         |
| Movement             | One original directed edge per march, once per army per season, one action. Foreign passage requires war or alliance. Mounted troops retain a simplified mountain restriction. Raw movement codes are displayed but original weighted semantics remain unknown |
| Warfare              | Deterministic auto-resolution using troop power/strength, terrain, forts and defenses. Ties favor defenders. Defeat destroys losing units; victors suffer bounded casualties. Occupation and contested state are separate from sovereignty                     |
| Diplomacy            | Initially neutral runtime relationships; original raw matrices remain preserved. Peace/pact/alliance/war use transparent compatibility thresholds. Negotiation costs 1 GB, 2 RP and one action; rejected offers still cost resources                           |
| Forts                | Individual original castles and wizard towers are retained. Construction is limited by province level; original forts up to schema limit 15 survive import. Wizard towers do not invent castle defense                                                         |
| Events and AI        | Seeded enhanced event table and existing planner, with valid actions and normal budgets; original personalities and special NPC logic are not yet reconstructed                                                                                                |
| Survival             | Active domains survive while they retain sovereignty, positive holdings, armies or forts. Holding-only domains are not eliminated for having no provinces. Passive records persist                                                                             |
| Victory              | Experimental domain-power target 600, or highest domain power after 80 seasons                                                                                                                                                                                 |

**Classic / Enhanced** are rules profiles. Classic expires wars seasonally and prevents a last-action declaration; Enhanced keeps wars until peace. Both retain simplified development, diplomacy and combat. Neither is a complete reproduction of the 1997 rules.

**CLASSIC / UNRESTRICTED** faction availability is a separate configuration. Original selectability flags are preserved independently of technical support and selection overrides. The current UI exposes 18 eligible regents. Nonterritorial player campaigns, classless rulers and special factions require further investigation; unused records are not assumed playable.

Trade-route creation, investiture, tactical battles, sieges/retreats, realm magic and RPG adventures are unfinished. Original save character tails and exact post-New-Game transformations are not reconstructed. No prototype spell is offered in Anuire.

Detailed original rule descriptions and help-section references are preserved in the [research archive](archive/GAME_MECHANICS_REFERENCE.md). See [Anuire data](ANUIRE_DATA.md) for verified records and [known issues](KNOWN_ISSUES.md) for specific gaps.
