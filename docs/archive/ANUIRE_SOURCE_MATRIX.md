## Source priority and confidence

`HIGH_OBSERVED_TEMPLATE` means a value was decoded from a hashed original record with validated references. It describes the stored template, not every downstream rule calculation. `EXACT_AT_ORIGINAL_HIT_MAP_RESOLUTION` describes cell-edge contours of the province ID raster; it does not certify continuous HD coastlines. Independently agreeing PC guide values are stronger evidence and have separate comparison rows. `SECONDARY_TABLETOP_ONLY` never overrides a PC record. `INFERRED` / `ENHANCED_DESIGN` identify the compatibility projection's explicit M0 policy values. Missing fields remain missing.

Each private campaign record has a stable index-based ID, source offset, source IDs, confidence and scope. The top-level source manifest contains SHA-256, byte length and hash scope. Original strings retain pointer/file offsets; map geometry links to the hashed map archive. External guide and atlas snapshots are hashed when present. Source revision and guide version are recorded separately.

## Cross-source results

The guide parser recovered 200 province rows, 604 holding/fort rows, 63 domain regent summaries and 62 detailed character profiles. It compared 591 province field values with no differences, 586 holding rows with seven differences, and 488 character field values with eight differences. Three province names and 11 holding rows remain unmatched under exact normalized spelling. Counts are comparisons, not additional unique campaign records. [Machine-readable coverage](../../reference/extracted/anuire/coverage.json) records the current run.

Examples requiring explicit separation:

- Guide `Caudright`, `Dharileine`, `Abattuor` differ from CD `Caudraight`, `Dharilein`, `Abbatuor`. Candidate spelling correspondences are not silently accepted by the importer.
- Guide/CD discrepancies concern seven holding observations: Daulton guild, Mhelliviene guild, Ruorkhe source, Hidaele law, Achiese law, Caerwil law and Serimset law. Raw values and line references are in private `source-cross-checks.json`; no secondary value overwrites the CD.
- One character difference is Fhiele Dhoesone's Constitution (CD avatar 15, guide 14). Seven concern the Spider's six attributes/HP: CD text has zero/default values while the guide reports initialized values. Zero is preserved as observed, not presented as a complete monster stat block.
- The [Roesone tabletop table](https://birthright.net/wiki/index.php/Roesone) gives Caercas source potential 5; both the private PC template and the PC guide give 1. Its development is 4 in both. The separate tabletop report preserves that disagreement.
- The modified source opens additional realm selection; the private CD template has 18 playable flag bits. Neither establishes every stock menu restriction for every historical version.
