# Changelog

## Repository cleanup

One application/build now includes original graphics/audio and the default Anuire dataset. Removed the separate public/private pipelines, procedural product UI and prototype campaign selection. Synthetic geography remains only as a test fixture. Missing inputs open setup/import diagnostics. Original resources are retained in full, including future battle/RPG assets. Current documentation is consolidated; detailed research is archived.

## M1C — classic presentation

Recovered 9,501 asset records from 13 archives and nine music files. Integrated original map art, shield menu, portraits, classic council layout, soundtrack and effects. Added read-only bitmap/FLC/palette/audio decoding, browsable catalog, media controls and 1920×1080 comparison captures. Fixed asynchronous map initialization and documented missing cues/fonts/heraldry.

## M1B — playable Anuire

Imported 206 provinces, 51 domains, 116 regents, 766 holdings, forts and deployments. Added large-world geometry/interaction, holding-only domains, source-preserving availability policies, occupation, scenario-fingerprinted saves and deterministic AI/simulation coverage. Both rule profiles remain experimental.

## M1A — original data reconstruction

Implemented read-only CD/resource/string/save/template research, linked original identities and hit-map geometry, validated references and documented offsets/source conflicts. Kept evidence-backed facts separate from provisional gameplay rules.

## M0 — strategic engine

Established the deterministic command engine, economy, diplomacy, recruitment/movement, auto-combat, seasonal AI, save/load, React/Pixi interface and Tauri wrapper using synthetic test geography. That fictional campaign is no longer part of the application.
